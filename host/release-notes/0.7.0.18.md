## What's new in 0.7.0.18

**Desktop Mode installs again**
- On a Portalistic set up since the end of October, switching to Desktop Mode ended with "Desktop Mode didn't install completely". Fedora moved KDE to Plasma 6.8, which no longer has the X11 desktop Desktop Mode runs on.
- Desktop Mode now installs KDE Plasma 6.7.5, the last version with it, and keeps it there: Plasma, Qt and the KDE apps stay at versions known to work, and system updates leave them alone. Packages Fedora's servers no longer offer come from Fedora's own build archive, each checked before it's installed.
- A Linux system that got Plasma 6.8 is put back on 6.7.5 at the next switch to Desktop Mode (or when it installs in the background).
