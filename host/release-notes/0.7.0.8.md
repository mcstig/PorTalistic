## What's new in 0.7.0.8

**Games set up and install much faster, and no longer hang there**
- Each Windows game has a folder of its own that Proton sets up the first time (its "prefix": thousands of small files). Portalistic kept it in your game folder on the Mac, and writing it through the Mac's file sharing was slow: on a 2020 M1 MacBook Pro a game's first start took about 9 minutes, and Steam's last install step (the game's DirectX and Visual C++ installers) took long after the download said it was done. On that Mac, the file sharing also sometimes lost a request, and the game or the install then waited forever.
- These folders now live on Portalistic's Linux system's own disk. The ones you already have are copied there once, at the next Steam start; the originals stay in your game folder on the Mac. Each takes about 150 to 400 MB of the Linux system's 20 GB.
- While Steam runs a game's installers after a download, a banner now says "Finishing the install of <game>", so it no longer looks stuck.

**Good to know**
- This release reuses the Linux image of 0.7.0, so there is no big download. Copies of 0.7.0.3 to 0.7.0.7 offer the update when they open.
