## What's new in 0.7.0.17

**Desktop Mode is ready when you want it**
- Desktop Mode now installs itself in the background after Portalistic's first start (about 550 MB), so the first switch no longer waits for the download. The emulators it comes with (Ryujinx, RPCS3, Play!, RetroArch) follow, as before.
- It runs at the lowest priority and waits while a game is running. Stopped by Quit, it carries on at the next start.
- Switching to Desktop Mode before it's done shows its progress and carries on from there, instead of starting again.
