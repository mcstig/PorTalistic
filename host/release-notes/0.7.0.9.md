## What's new in 0.7.0.9

**Game folders are drives now: games start, and installs finish**
- On some Macs (a 2020 M1 MacBook Pro on macOS 26.3.1 in our tests) the way the Linux system reached your game folder sometimes never answered a request, and a game's start, or Steam's last install step, waited forever. Each game folder now holds a drive, "Portalistic Games.img", that the Linux system uses the same way as its own disk, which never had that problem. The file is sparse: it takes space on your Mac only as games fill it, and gives it back when you uninstall them.
- The games already in your folders move into the drive once, the first time Steam starts after this update. A window shows which game is moving and how far it is. This can take a while (about a minute per 5 GB on a fast drive); nothing is deleted until a game is safely in.
- Steam sees the drive sized to what your Mac really has free, so it can't start a download your Mac can't hold.

**A "please wait" window while Steam gets ready**
- After an update, or whenever Steam starts, Portalistic does some work first (bringing its Linux system up to date, moving games, setting games to their Windows versions, getting DXVK ready). The window used to stay black meanwhile. Now a small window says what is happening, and goes away when Steam is on screen.

**Faster updates**
- Two graphics checks that ran at every update (a minute or more on slower Macs) now run only when the graphics pieces they check have changed.

**Good to know**
- This release reuses the Linux image of 0.7.0, so there is no big download. Copies of 0.7.0.3 to 0.7.0.8 offer the update when they open.
- To go back to plain folders: `BOTTLE_GAME_DISKS=0` in `~/.config/steamos-bottle/host.env` (not recommended).
