## What's new in 0.7.0.6

**Games stay off the Linux system's drive**
- When you install a game, Steam also offers its own drive: the 20 GB one that holds Linux, Steam and Proton. A big game filled it, Steam then said it was out of space every time it started, and Settings > Storage > Move did nothing. Now, if a game starts installing there, Portalistic stops it within a minute, deletes what was downloaded, restarts Steam and tells you to set **Install to** a game folder (Mac). Proton and Steam's other tools still go on that drive. A game that is fully installed there already is left alone.
- The low-space messages no longer send you to Move; they say to install the game to a game folder.

**Fixed**
- Steam's browser part wrote an error to two log files about every frame. Over two weeks they grew past 10 GB and filled the Linux drive. They are now emptied whenever one passes 50 MB, and **bottle disk clean** does it too. `bottle disk` also lists the biggest folders on the drive.

**Good to know**
- If your drive is already full, update, then Restart Steam: the cleanup runs while Portalistic is open. A partly downloaded game on that drive is removed when Steam starts it again.
- This release reuses the Linux image of 0.7.0, so there is no big download. Copies of 0.7.0.3 to 0.7.0.5 offer the update when they open.
