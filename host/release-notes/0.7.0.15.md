## What's new in 0.7.0.15

**Smoother games: shaders compile far less**
- Games that build lots of graphics pipelines (CS2, for one) stuttered or froze for seconds while the Mac compiled the same shaders again and again. In CS2's Advanced Video menu, 3,950 compiles turned out to be only 87 different shaders. Portalistic now keeps each compiled shader and hands it out again, so a repeat costs nothing.
- Some vertex shaders were refused by the Mac's graphics (a detail Metal doesn't allow in them) and were retried endlessly. Portalistic now mends them before compiling, and remembers any compile that still fails instead of retrying it.

**When a game doesn't work**
- A banner says why a game closed, and now has buttons: **Install … and try again** when a missing Windows library is the reason (Portalistic installs it with Winetricks), and **Report this problem…**, which saves a report to your Desktop and walks you through sending it as a GitHub issue.
- Portalistic carries a list of games known not to run here and why: anti-cheat that refuses Linux (Battlefield, Call of Duty, PUBG, Rainbow Six Siege, Apex…), copy protection that doesn't pass the x86 translator (Forza Horizon 5 and 6, Age of Empires IV, Flight Simulator 2020…), games that need hardware ray tracing. Such a game now says so as it starts. The list updates itself daily.
- A crashing Windows game no longer leaves a black screen for minutes (Wine's crash debugger is off).
- Long banner texts scroll.

**GOG and Epic**
- Pause and Stop for a running download (Pause keeps what came down; Install picks it up again), and a queue: pick more games while one downloads.
- Reinstalling a game you had deleted by hand failed with "couldn't find which program starts it" (GOG) or "No write access" (Epic). Fixed.

**Mouse and quitting**
- Release the mouse with **Control and Option pressed together (⌃⌥)**. ⌘Esc now opens macOS's own game overlay, so Portalistic doesn't use it any more.
- Store launchers (REDlauncher, GOG Galaxy, Ubisoft Connect…) and Steam's Big Picture screens never capture the mouse: the pointer stayed frozen in the middle of their windows.
- **Quit shuts the VM down at once**, games included: it doesn't wait for Steam or a game, so a frozen game can no longer keep it running. The window shows the VM shutting down and Portalistic closes once it has stopped (a few seconds), so it can be opened again right away. (Steam > Shut Down the VM… still closes Steam properly first.)

**Game drives**
- A drive with Portalistic games on it, from another Mac or from before a reinstall, is added by itself when Portalistic starts, and keeps its name. Plugging it in while Portalistic runs offers to use it. A drive you removed from Game Folders stays removed.

**Smaller things**
- Messages name the app's menus (Steam > Update the VM) instead of Terminal commands.
- Portalistic waits for the Linux system to answer after it starts, instead of reporting a missing part.
- Old logs are tidied away; the Linux system's journal and the VM's own log are kept small.

**Known issue**
- Counter-Strike 2 can freeze on team selection or the first spawn: part of its graphics setup is refused on the Mac. Being worked on. If it happens, ⌘Q, then Quit, ends it.
