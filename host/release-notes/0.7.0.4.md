## What's new in 0.7.0.4

**GOG and Epic Games**
- A new **Stores** menu with **GOG Games…** and **Epic Games…**. Sign in on the store's own web page, paste the code it gives you back into the window, and you see the games you own as cover art. Install, update and remove them from there. They download inside Portalistic's Linux system and show up in Steam's library and Big Picture, in a "GOG" or "Epic Games" collection, and run through Proton like Steam games. Epic uses the open-source [Legendary](https://github.com/derrod/legendary).
- Installed games come first and the ones you don't have yet are in black and white. A sort menu orders by name (A to Z or Z to A) or by release year (newest or oldest first). The cover under the mouse pops out.
- GOG games show their real cover, banner and logo in Big Picture instead of a blue tile.
- GOG games that use GOG Galaxy's online features (GWENT, for one) now start and connect: Portalistic includes [Comet](https://github.com/imLinguin/comet), an open-source stand-in for the Galaxy service, running inside the Linux system while the game does.
- The game-folder actions (Add, Remove, Show) moved from the Bottle menu into their own **Game Folders** menu.

**32-bit Windows games**
- 32-bit games (many older GOG and Steam titles) now run. They needed their own 32-bit graphics driver and display layer; both are included.
- Fixed: after a Proton update, installing the DirectX translation (DXVK, vkd3d-proton) could stop halfway on read-only files. That affected every Proton game.

**Desktop Mode**
- **Bottle > Switch to Desktop Mode…** gives you a KDE Plasma desktop, like the Steam Deck's, and **Switch to Game Mode** goes back to Big Picture (also `bottle mode` in Terminal). The first switch downloads about 550 MB (about 1.3 GB on disk). The desktop has a Steam launcher, "Return to Game Mode", the Discover app store (Flathub apps only), and Dolphin lists your game folders.
- Updating the Linux tools while Steam runs no longer leaves Big Picture without its fullscreen window.

**Good to know**
- Epic Games is the newest part and has had the least testing. DLC and cloud saves aren't handled yet for GOG or Epic.
- Games that use anti-cheat or copy protection (Denuvo, Easy Anti-Cheat and the like) still don't run; Portalistic doesn't work around them.
- Steam's window can cover the desktop right after switching to Desktop Mode; the Steam launcher opens it again. A game can't be running when you switch.
- This release reuses the Linux image of 0.7.0, so there is no big download. Copies of 0.7.0.3 offer the update when they open.
