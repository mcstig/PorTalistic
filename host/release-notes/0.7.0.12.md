## What's new in 0.7.0.12

**"Move to Applications" works**
- Since 0.7.0.1, clicking "Move to Applications" on a freshly downloaded copy quit the app on the spot instead of copying it: the question is asked before the window exists, and the question closing counted as the last window closing. Now the copy is made, opened from Applications, and the download goes to the Trash, as the dialog says.
- What the move does is written to `~/Library/Logs/Portalistic/app-install.log` (Save Logs includes it).

**Good to know**
- This release reuses the Linux image of 0.7.0, so there is no big download. Copies of 0.7.0.3 to 0.7.0.11 offer the update when they open.
