## What's new in 0.7.0.13

**Games you already have are found again**
- After a reinstall of Portalistic that kept the game folders (or on a Mac with a game folder from before), the games in them come back: Steam adds the folder at its first start (Steam restarts once, with a banner saying so), and the GOG and Epic games in the folder get their Steam entries back without downloading anything (Epic's need the Epic sign-in first; they are picked up once you sign in).
- A "Portalistic Library" folder on a connected drive is added again when Portalistic is set up.
- The same check runs every time Steam starts: a game folder Steam's list dropped (Settings > Storage) is put back.

**Good to know**
- This release reuses the Linux image of 0.7.0, so there is no big download. Copies of 0.7.0.3 to 0.7.0.12 offer the update when they open.
