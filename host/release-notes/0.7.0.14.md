## What's new in 0.7.0.14

**Network shares from the Linux desktop**
- In Desktop Mode, Dolphin's Network place lists the file servers on your network (NAS, other Macs with File Sharing or Remote Login on) by name, and opens them as smb://, nfs:// or sftp://. Type a server address in Dolphin's bar too (smb://nas/share). Names like nas.local work, although the Linux system sits behind your Mac's network: Portalistic looks the servers up on the Mac and passes them on, every few minutes.
- The tools for it (Samba client, CIFS and NFS mounts) come with Desktop Mode (a small download the first time Desktop Mode opens after this update).

**Signed in elsewhere**
- When your Steam account signs in on another computer, Steam in the bottle loses its session and an install then says there's no internet. Portalistic now shows a banner saying what happened and that Steam > Restart Steam signs in again.

**First start**
- The first time Portalistic shows Steam on a Mac, a short "Welcome" note says what to expect: some games need a second or third start, Steam > Restart Steam if Steam is stuck, no anti-cheat games. It's under Portalistic > Good to Know… after that.

**Desktop Mode**
- Discover opens without asking for a password (it wanted root for a system-wide Flatpak repository and for firmware updates; neither applies here).
- KDE's wallet is set up once (empty password works), so a network share's password is remembered without repeated wallet wizards.
- The panel's spinners and fades run at normal speed (they were paced by a screen refresh rate the VM doesn't report).
- Restart Steam from Desktop Mode brings Steam back (it used to start too early and give up with "another instance").
- Dolphin's places for game folders open the drive, where the games are. A folder's empty leftovers from before the drive are removed by Portalistic's housekeeping.
- .NET programs (Ryujinx, for one) crashed at random on M4 Macs: Apple's SME extension is now hidden from the Linux kernel.
- The drive is no longer trimmed on every delete; deleted files survive on it until the next housekeeping round.

**The Linux system's disk**
- New installs get a 25 GB disk (was 20): Proton, its runtimes and FEX live there, and they have grown. It takes Mac space only as it fills.
- When the Linux system's disk runs low, Portalistic asks what you want: make it 5 GB bigger (it takes Mac space only as it fills; Steam restarts), or move the games on it to a game folder in Steam's storage settings.
- GOG and Epic games keep their Windows prefix (saves, settings) in their game folder now, not on the Linux system's disk; existing ones move at the next Steam start.
- Installing a game onto the Linux system's disk is cancelled with a clearer explanation of why that's a bad idea and where to install instead.

**Good to know**
- This release reuses the Linux image of 0.7.0, so there is no big download. Copies of 0.7.0.3 to 0.7.0.13 offer the update when they open.
