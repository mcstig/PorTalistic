## What's new in 0.7.0.5

**Installing and uninstalling**
- Open Portalistic from Downloads (or anywhere outside Applications) and it offers to move itself to Applications. **Move to Applications** copies it there, checks the copy, opens it and moves the downloaded one to the Trash. **Not Now** starts it where it is; "Don't ask again" stops the question, and **Portalistic > Move to Applications…** does it later. If an older Portalistic is already in Applications it is replaced; if the same version is there, you are offered to open that one.
- **Portalistic > Uninstall Portalistic…** lists what it will delete (the Linux system, settings, logs and downloaded updates, with their sizes), then deletes it and moves the app to the Trash. Your game folders stay where they are unless you tick **Also move my game folders to the Trash**; they go to the Trash, not away for good.

**Good to know**
- Both are new and were tried on test folders and a stand-in for the Linux system, not yet on real Macs. If something doesn't work, the app says what went wrong and which files it means, and you can delete those yourself.
- This release reuses the Linux image of 0.7.0, so there is no big download. Copies of 0.7.0.3 and 0.7.0.4 offer the update when they open.
