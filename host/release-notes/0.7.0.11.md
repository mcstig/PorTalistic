## What's new in 0.7.0.11

**Waiting looks like waiting**
- While Steam isn't up yet (the Linux system updating, games moving into a drive, Steam starting), Portalistic shows a card in its own window saying what it's doing, instead of a black window or a separate "please wait" box that didn't always appear.
- The Activity window (Restart Steam, Update the VM, Save Logs, Shut Down…) is a list of steps with a tick as each finishes; the raw output is behind "Details".

**The Steam menu**
- The Bottle menu is now **Steam**, with **Start the VM** and **Update the VM** (was Start the Bottle, Update the Bottle). Messages everywhere point at the new names.

**GOG and Epic**
- Store covers: installed games in colour, the rest in black and white, and a cover turns to colour as the mouse reaches it.
- A game you install from GOG or Epic lands at the front of Steam's Recent row, like a newly installed Steam game.

**Smaller things**
- Pressing ⌘ Esc to free the mouse no longer jumps the pointer to the middle of the window; it is back where it was.
- Uninstall shows how much each game folder's drive takes.
- A stale "X closed after N s" notice no longer pops up on every Steam restart.
- Portalistic now asks for a Mac with 8 GB of memory or more (4 GB left the VM too little for Steam and a game).

**Good to know**
- This release reuses the Linux image of 0.7.0, so there is no big download. Copies of 0.7.0.3 to 0.7.0.10 offer the update when they open.
