## What's new in 0.7.0.10

**GOG and Epic games move into the drive too**
- 0.7.0.9 moved only Steam's games into the game folder's new drive; GOG and Epic games stayed behind and exited at once when started. They move now, the same way, with the progress window.

**The move no longer waits on the old folder**
- Deleting the old copies went through the same file sharing that could hang. The Linux system now only notes what moved, and your Mac deletes the old copies itself, which is instant.
- The "please wait" window now appears during the Linux system's update too, not only once Steam gets ready.

**Good to know**
- This release reuses the Linux image of 0.7.0, so there is no big download. Copies of 0.7.0.3 to 0.7.0.9 offer the update when they open.
