## What's new in 0.6.21

- **PorTalistic offers to set up a Wine container when it opens**, if the Wine build your games run on doesn't have one yet — so the first Play doesn't spend a minute building it. Choose Not Now and it's made the first time you press Play, as before.
- **The update check tries again** a minute later if the first attempt fails, for example when the app opens before the network is back.
- **The update prompt fits on screen.** Release notes wrap instead of stretching the window to their longest line.
- The version you have is shown in full — "0.6.20 (74)", not "0.6+74".
