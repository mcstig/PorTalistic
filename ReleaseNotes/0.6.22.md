## What's new in 0.6.22

- **Wine 11.16 (DXMT) is now the default for every game.** The Mythic Engine (Wine 7.7) is only the fallback when a game can't run on it. PorTalistic downloads the build if it isn't there yet, and always installs Direct3D 11 on Metal (DXMT) into it — so Direct3D 11 games such as Bloodstained start, including Unreal games, whose launcher gives nothing away about how they render.
- **PorTalistic notices a Wine build with no container** — when it opens, and right after you delete one — and offers to set it up. Previously it only looked at the build each game would pick, which was usually the Engine, so it never asked about Wine 11.16.
- **The Containers page marks the default build's container**, and the Engine's container is named "Mythic Engine" rather than "Default".
- A GOG game that can't be started says what's missing — its folder, its info file, or a play task — instead of only "couldn't work out how to start it".
- Setting up a container at the prompt shows progress in the sidebar; if it fails, you're told why, with Show Log. New containers default to the newest Wine build.
