## What's new in 0.6.22

- **Wine 11.16 (DXMT) is now the default for every game.** The Mythic Engine (Wine 7.7) is only the fallback when a game can't run on it. Games already set up on the Engine move over automatically; PorTalistic downloads the build if it isn't there yet.
- **PorTalistic notices a Wine build with no container** — when it opens, and right after you delete one — and offers to set it up. Previously it only looked at the build each game would pick, which was usually the Engine, so it never asked about Wine 11.16.
- Setting up a container at that prompt shows progress in the sidebar; if it fails, you're told why, with Show Log.
- New containers default to the newest Wine build in the Containers "+" sheet.
