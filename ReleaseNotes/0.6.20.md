## What's new in 0.6.20

- **Games that need Wine 11.16 start on any Mac.** Setting up its container failed with "Wine stopped before its Windows environment was ready" even though Wine had finished: PorTalistic waited for a message newer Wine no longer prints, then removed the container.
- **When a container can't be set up, you're told why**, and **Show Log** opens the details in Finder.
- **Check for Updates…** is in Settings ▸ General.
- **Wine 11 games start a little faster:** their Windows version is no longer set again before every launch.
- The Home page shows the PorTalistic banner until you've played something.
